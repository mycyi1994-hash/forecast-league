`calldata.txt` 전체를 inputData로, BNB Chain(56)의 결정적 배포 팩토리 `0x4e59b44847b379578588920cA78FbF26c0B4956C`에 value 0으로 보냅니다. 배포 직후 빌더 지갑이 1번 패스를 받습니다(외부 민팅은 빌더의 첫 민팅 뒤에 따라옵니다).

## 배포 뒤

1. Sourcify 인증 제출, BscScan 초록 체크 확인(`standard_json_input.json`, `constructor_args.txt`).
2. 제출 폼에 주소 추가(사장님).
3. 피드(`keeper/finalspass.mjs`), 민트 데스크, 사이트, 안내서에 추가.

## 파일

- `calldata.txt`: 팩토리에 보낼 inputData (salt 0 + 생성 코드 + 생성자 인자)
- `constructor_args.txt`: 생성자 인자 (Agent ID 등록부 + 리그 계약 12개, 얼리 패스와 동일)
- `standard_json_input.json`: 소스 인증용
- `address.txt`: 배포될 주소
