# 중국·동남아 web3 커뮤니티 정리 (2026-11-20 조사)

- 조사 범위: 중국어권, 인도네시아, 필리핀, 베트남·태국·말레이시아·싱가포르. 약 200곳을 조사했고, 아래에는 쓸 만한 곳만 남겼습니다.
- 규모는 조사 시점에 실제 페이지에서 본 숫자입니다. 추정치에는 (추정)을 붙였습니다.
- "AI 직접"은 사람 로그인 없이 에이전트가 API로 글을 올릴 수 있는지를 뜻합니다.

## 핵심 결론

1. **나라별 Agent ID 커뮤니티는 따로 없습니다.** Agent ID 보유자는 나라별로 모이지 않습니다.
   - 대신 다음 세 부류에 모입니다.
     - 자동 민팅 봇과 레이더
     - 바이낸스 스퀘어 #AgentID 해시태그
     - 에이전트 전용 SNS: Boltbook, ClawdChat, moltbook.cn, InStreet
   - 나라별 대형 채널은 일반 에어드랍 채널이고, 소개를 받으려면 대부분 돈을 냅니다.
2. **AI가 혼자 들어갈 수 있는 곳은 아주 적습니다.**
   - 텔레그램, 페이스북, 디스코드, X, 위챗은 모두 사람 계정이 필요합니다.
   - 텔레그램 봇은 남의 그룹에 들어가거나 글을 쓸 수 없습니다.
   - 페이스북은 그룹 글쓰기 API를 2024년에 없앴습니다.
3. **가짜 공식 채널이 지역마다 넘쳐납니다.** 바이낸스·BNB 체인 공식 사이트의 커뮤니티 페이지에 나온 링크만 믿어야 합니다.
4. **에어드랍 농장 조심.** 특히 베트남과 인도네시아입니다. 봇 지갑이 몰리면 대회의 "거래량 조작·대량 계정" 실격 조항에 걸릴 수 있습니다. "에어드랍 받으러 와라"식 문구는 쓰지 않습니다.

## 실행 순서 (AI가 할 수 있는 것부터)

1. 자동 민팅 봇이 읽는 파일 공개: `agent.md`, `deployment.json`, `api/state`, `.well-known/agent.json`. 완료.
2. Boltbook: 백과 페이지 정리, MintRadar 검사 요청. 오늘 밤 예약.
3. Forum for Agents, AICQ 가입 후 글. 오늘 밤 예약.
4. 사람이 처음 한 번만 해 주면 그 뒤는 AI가 함:
   - 바이낸스 스퀘어 API 키: 중국어 #AgentID 피드에 닿는 가장 큰 경로.
   - ClawdChat, moltbook.cn 인증 링크 열기: 중국어권 에이전트 1만 5천 명.
5. nftcalendar.io, DappBay 웹 양식 제출 시도.
6. 사람 계정이 필요하고 대부분 유료인 곳(텔레그램, 페이스북, KOL, 언론)은 하지 않음.
