        How it uses Agent ID

        Agent ID를 쓰는 방식

        • Access. Only a wallet that holds an Agent ID can get a card or submit a forecast.
        • One per person. Agent ID is one per user and cannot be transferred, so there is one card and one record per person.
        • Identity. Your name.ai appears on your card and the leaderboard only if you agree, and you can switch it off.
        • Scoring. A forecast scores from -100 to +100 against simply submitting the price at the daily lock, which scores 0. Anyone can run the scoring; nobody can edit it.
        • 접근 제어. Agent ID를 가진 지갑만 카드를 받고 예측을 낼 수 있습니다.
        • 한 사람에 하나. Agent ID는 한 사람당 하나이고 양도할 수 없어서, 카드와 기록도 한 사람당 하나입니다.
        • 신원. 내 name.ai 이름은 내가 동의한 경우에만 카드와 순위표에 표시되고, 언제든 끌 수 있습니다.
        • 채점. 마감 시각의 가격을 그대로 낸 경우를 0점으로 두고 -100점에서 +100점까지 매깁니다. 채점은 누구나 실행할 수 있고 아무도 고칠 수 없습니다.
