What this page does not show

  • Claims, squad calls and the daily price forecast leave no token, so they are not counted. Real transaction counts are higher than the token counts here.
  • One person can own more than one Agent ID wallet only if they hold more than one Agent ID. This page cannot tell who is behind a wallet.
  • Many of these wallets are run by software that takes any free, zero-value mint it finds. A mint is not proof that a person cared.
